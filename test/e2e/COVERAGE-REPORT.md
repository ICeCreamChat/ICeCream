## 测试辅助工具 (Test Helpers)

### 等待策略
- `waitForInteractive()` - 等待元素可交互
- `waitForAnimationEnd()` - 等待动画完成
- `waitForNetworkIdle()` - 等待网络空闲

### 性能测量
- `measureResponseTime()` - 测量操作响应时间
- `measureFPS()` - 测量渲染帧率
- `measureMemoryUsage()` - 测量内存使用
- `capturePerformanceMetrics()` - 捕获性能指标

### 交互工具
- `scrollToElement()` - 滚动到元素
- `touchSwipe()` - 触摸滑动
- `isInViewport()` - 视口检测

### 监控工具
- `ConsoleCollector` - 控制台日志收集
- `NetworkInterceptor` - 网络请求拦截与模拟

## 运行命令

### 本地开发
```bash
# 运行全部 E2E 测试
npm run test:e2e

# UI 模式（推荐用于调试）
npm run test:e2e:ui

# Debug 模式
npm run test:e2e:debug

# 查看测试报告
npm run test:e2e:report

# 有头模式（看到浏览器）
npm run test:e2e:headed
```

### 分项目运行
```bash
# 仅运行桌面端 Chrome
npm run test:e2e:chromium

# 仅运行桌面端 Firefox
npm run test:e2e:firefox

# 仅运行移动端
npm run test:e2e:mobile

# 仅运行性能测试
npm run test:e2e:performance
```

### CI 环境
```bash
# CI 会自动执行
playwright test --project=<matrix-project>
```
